## Selected work

### Reliable Survival Model Evaluation
Investigating when performance metrics and model rankings become unreliable under censoring and partially observed outcomes.  
[ICML 2026 paper](https://proceedings.mlr.press/v306/bahrini26a.html)

### Synthetic Data Under Censoring

[KDD 2026 paper](https://doi.org/10.1145/3770855.3817857)
